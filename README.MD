# TUXXY
Cool Discord bot we cooked up for our Uni Discord server.

### FEATURES
- Type `@Tuxxy` to say hello to Tuxxy
- If somebody other than an approved list of members join the server, Tuxxy kicks them out automatically
- When somebody joins a voice channel to study, it tags everyone, to tell them that the person is studying, so as to encourage the others to study with them
